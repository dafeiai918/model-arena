# model-arena · 模型擂台盲测榜

**别信跑分，信你自己的眼睛。** 同一个问题问两个模型，盲测投票，生成本地 Elo 排行榜。

零依赖 · 单文件 · 中文 · 数据全在本地

---

## 为什么需要盲测

- 榜单上的跑分和你的实际需求往往不匹配
- 模型名会带来偏见——看到 "GPT" 就默认更好
- 中转站的模型**可能不是你以为的那个**，只有自己测才知道

本工具把模型名藏起来，只给你答案 A 和答案 B，你选更好的那个，剩下的交给 Elo。

---

## 快速开始

```bash
# 1. 配置站点
python model_arena.py setup -u https://api.example.com/v1 -k sk-xxxx

# 2. 看看站点有哪些模型
python model_arena.py fetch

# 3. 挑几个参赛（建议同价位、同规格的放一起比）
python model_arena.py models add gpt-4o-mini deepseek-chat qwen-plus glm-4

# 4. 开始对战
python model_arena.py battle "用三句话解释什么是向量数据库"

# 5. 看排行
python model_arena.py board
```

## 命令一览

| 命令 | 说明 |
|---|---|
| `setup -u 地址 -k 密钥` | 配置站点 |
| `fetch` | 拉取站点可用模型列表 |
| `models add/remove/clear/list` | 管理参赛模型 |
| `battle [问题]` | 开始一轮盲测（不传问题会提示输入） |
| `board` | 查看排行榜 |
| `reset` | 重置所有对战记录 |

---

## 玩法建议

| 玩法 | 做法 |
|---|---|
| **同价位对决** | 把所有便宜模型放一起，看谁的性价比高 |
| **验证中转站质量** | 同一个模型名在两个站各建一条（用 `models` 手动命名如 `站A-gpt-4o`） |
| **任务专项榜** | 只问代码题 → 得到「代码能力榜」 |
| **新人选模型** | 挑 3 个候选，打 20 轮，看哪个稳定 |

## 数据位置

- `~/.model-arena/arena.db` — 对战记录与 Elo，全部本地
- `~/.model-arena/config.json` — 站点配置与参赛模型

---

## 说明

- 每轮对战会消耗 2 次 API 调用（你自己的额度）
- 投票结果只代表**你的偏好**，不代表绝对能力
- 样本量建议 20 轮以上再下结论
